# DotGrid для KDE Plasma 6

[English version](README.md)

Тема «день/ночь» для KDE Plasma 6, построенная на сетке точек с шагом 40 px, с живыми обоями.

## Тема

- цветовые схемы KDE **DotGridDay** и **DotGridNight**
- цвета Konsole и kitty в тон, шрифт JetBrains Mono, логотип fastfetch
- точечные темы значков **DotGrid** / **DotGrid-Dark**: значки панели и трея (батарея, сеть, звук, уведомления, яркость, Bluetooth, клавиатура, буфер обмена, устройства, плеер, ночная подсветка), логотип меню запуска, папки, корзина, диски и закреплённые приложения. Всё остальное — около 7000 значков Breeze и значки установленных приложений (hicolor) — переводится в точечную матрицу автоматически (**DotGrid-Auto**, `tools/dotify_icons.py`). Все значки перекрашиваются по цветовой схеме. Вместе с ними ставится стиль Plasma **DotGrid** (Breeze с этими значками трея).
- точечный **курсор**: SVG для Wayland (резкий при любом масштабе) и Xcursor 24–96 px для программ под XWayland; анимированное ожидание; редкие формы — из Breeze
- виджеты **«Системный монитор»** точечной матрицей цвета текста темы (столбец на ядро ЦП, бегущая история для сети и памяти)
- **Zen Browser / Firefox**: цвета темы, точечная сетка за вкладками, JetBrains Mono (`./install-browser.sh`, затем перезапуск браузера)
- **рамки окон** (Aurorae): плоский заголовок в цветах темы, тонкая рамка, точечные кнопки; дневной и ночной вариант переключаются вместе с темой
- заставка входа, следующая за темой, картинка экрана блокировки тема экрана входа SDDM и загрузочная заставка Plymouth (точечная сетка, 12 плиток прогресса загрузки) — по желанию. Экран входа выбирает день или ночь по солнцу: он работает до входа пользователя и не видит его тему.
- `dotgrid-theme day|night` переключает всё сразу; таймер systemd делает это на восходе и закате, которые считаются локально (без интернета) для главного города часового пояса системы; `LAT=`/`LON=` в `~/.config/dotgrid/schedule` (или `--lat`/`--lon`) задают место, `--day-at`/`--night-at` — переключение по часам; `dotgrid-auto --show` показывает время. Ручное переключение держится до следующего восхода или заката

## Живые обои (DotGrid Live)

Плагин обоев Plasma `org.dotgrid.live`, рисующий композицию вживую:

- **День:** часы `HH:mm:ss`, игра «Жизнь» Конвея на точках сетки, матрица букв 9×9, 12 плиток-прогресса и заряд батареи большими цифрами.
- **Ночь:** часы `unix | HH:mm:ss`, вращающаяся галактика из звёзд-квадратов, столбики 26×12 и трубы-индикаторы. Столбики и трубы показывают спектр звука, нагрузку системы (CPU, RAM, сеть) или генеративные волны. Маркеры J/M/I показывают час, минуту и секунду на точечных строках.
- **Пауза** из трея, глобальной клавишей (Meta+Shift+P) или командой `dotgrid-live`. Автопауза срабатывает при энергосбережении, низком заряде батареи и заблокированном экране. Часы идут и на паузе, всё остальное стоит и не тратит процессор.
- **Окно настроек:** у каждого элемента своя панель — скорости, число звёзд, правила «Жизни», перебор букв, что показывают плитки. FPS задаётся отдельно для дня и ночи. Интерфейс на русском и английском.
- **Замер нагрузки (по желанию):** CPU, память и разряд батареи раз в минуту, со свёрткой в сжатые почасовые снимки.

Без своих шейдеров: статичные слои рисуются один раз, галактика — один узел геометрии в небольшом модуле на C++.

## Требования

- KDE Plasma 6 (Wayland или X11), Qt 6.5 и новее
- Arch Linux или производный дистрибутив для автоматической установки пакетов; в других системах аналоги ставятся вручную

| Для чего | Пакеты Arch |
|---|---|
| тема | `plasma-workspace`, `kconfig` (`kwriteconfig6`), `curl`, `ttf-jetbrains-mono`, `librsvg`, `python-pillow` |
| сборка обоев | `cmake`, `ninja`, `gcc`, `qt6-base`, `qt6-declarative`, `kpackage` |
| трей, сервис, CLI | `pyside6`, `python-dbus` |
| столбики по звуку (по желанию) | `python-numpy`, `pipewire`, `libpulse` |

Шрифт Doto скачивается с Google Fonts при установке.

## Установка

Всё ставится в `~/.local` и `~/.config` текущего пользователя. `sudo` нужен только для недостающих пакетов, и установщик сначала спрашивает.

```sh
./install.sh                 # только тема
./install.sh --live          # тема + живые обои
./install.sh --live-only     # живые обои к уже установленной теме DotGrid
./install-system.sh          # экран входа + загрузочная заставка (нужен sudo; по отдельности ./install-sddm.sh, ./install-plymouth.sh)
```

Параметры `install.sh`: `--day` / `--night`, `--lat ШИРОТА --lon ДОЛГОТА`, `--day-at ЧАС --night-at ЧАС`, `--no-auto`, `--no-apply`, `--icons-day ТЕМА --icons-night ТЕМА`, `--no-icons`, `--no-cursor`, `--no-decoration`, `--no-monitors`, `--no-splash`, `--yes`.

Только значки, курсор, рамки окон и заставка (к уже установленной теме): `./install-look.sh`; прежние запоминаются, `./uninstall-look.sh` возвращает их.

Пакет Arch с живыми обоями (для всей системы):

```sh
cd packaging && makepkg -si
systemctl --user enable --now dotgrid-livectl.service
```

Затем выбрать **DotGrid Live** в «Настроить рабочий стол и обои».

### Удаление

```sh
./uninstall-live.sh          # вернуть статичные обои; --purge удаляет и настройки
./install-system.sh --uninstall   # экран входа и заставка загрузки; прежняя тема Plymouth вернётся
```

## Использование

| | |
|---|---|
| значок в трее | левый клик — пауза/продолжить; средний клик — настройки; меню: тема, источник столбиков, FPS, элементы, автопауза, язык, справка |
| `dotgrid-live` | `status`, `toggle`, `theme day\|night\|schedule`, `fps day\|night N`, `element ИМЯ on\|off`, `opt ЭЛЕМЕНТ КЛЮЧ ЗНАЧЕНИЕ`, `metrics` и другие; без аргументов показывает список |
| `dotgrid-theme day\|night` | переключить всю тему |
| `~/.config/dotgrid/live.json` | все настройки живых обоев |
